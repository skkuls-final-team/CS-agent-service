# Proposal: 문의 상세를 상담원 업무 흐름에 맞춰 다시 배치 (add-ticket-detail-layout)

## Why
문의 상세가 목업(약 1,460px)보다 훨씬 길고(약 4,000px) 복잡해 보인다(2026-11-01 사용자 지적, 예전 목업·최신 목업·저장소를 같은 문의로 나란히 비교).
원인: ① 같은 정보(기한·고객사·우선순위·유형)가 띠·머리·칩·판단 표·이력에 여러 번 나온다 ② "시스템이 판단한 것"이 근거 문장·입력칸까지 처음부터 펼쳐져 약 600px ③ 이력·메모가 전부 펼쳐져 있다 ④ 모든 상자가 같은 무게라 지금 할 일이 눈에 안 들어온다.

## What Changes
화면만 바꾼다. 서버·API·DB 변경 없음.
- 위: 머리 + **AI 요약 한 줄 + [원문 보기]**(요약이 없으면 원문 앞부분) + **지금 할 일 띠**(내 차례, 기한 문장, 검토 모드, **진행 단계 6칸**). 별도 붉은 경고 띠와 "AI 판단" 칩 줄은 없앤다.
- 가운데: 왼쪽 **답변 초안** | 오른쪽 **판단과 근거 / 고객이 보낸 것** 탭. 판단은 예전 목업처럼 한 줄씩(이름 | 값 | 돋보기), 근거는 돋보기를 누르면 창으로. 1차 응답 기한·해결 기한을 따로 적는다. 고객·제품·근거 절·고장 진단·이관 후보·수정·실행 기록은 [근거 더 보기]에 접는다.
- 원문 패널 기본값: P1·안전·설비 정지·복합·상세 검토 문의는 원문 탭을 처음부터 연다(요약만 보고 보내는 위험을 줄임). 나머지는 판단 탭.
- 아래: 내부 메모·이력은 접고 건수를 보인다.

## 하지 않는 것
- "발송 전 보완 N건"(목업 todos)은 이번에 넣지 않았다(서버가 주는 값 정리가 필요).
- 원문 패널을 판단 표와 겹쳐 함께 보는 방식은 하지 않았다(탭으로 번갈아 본다).
- 초안 카드 안의 중첩 상자(답변 초안 > 정보 요청 초안) 정리는 다음에 한다.

## 시험
SCR-03-AC-24를 새 배치로 바꾸고, 내부 메모·이관 메일 시험은 접힌 구역을 여는 단계를 넣었다. 판단 칸을 읽는 시험은 `?tab=system`으로 연다.
