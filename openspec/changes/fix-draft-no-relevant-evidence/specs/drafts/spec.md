## MODIFIED Requirements

### Requirement: 근거와 조회값만으로 답변 초안을 만든다 (FR-021)
초안 단계는 막는 항목이 없고 근거 후보가 있을 때 근거 절 본문, 조회값, 제공 항목, 유형별 뼈대를 넣어 고객 언어 답변 초안을 만들어야 한다(MUST)(근거: 명세서 FR-021 처리 1·3·4). 빠진 항목만 있으면 끝에 "가능하면 보내 주실 것" 한 줄을 넣게 해야 한다(MUST)(근거: FR-021 처리 1). 근거 후보가 없으면 초안을 만들지 않고 "근거 없음 — 상담원 작성 필요"를 표시해야 한다(MUST)(근거: FR-021 처리 2). 근거 후보가 있어도 그 후보와 조회값(부서 회신이 있으면 그것도)이 고객이 물은 것에 하나도 답하지 못하면 근거 없음과 같이 초안을 만들지 않고 "근거 없음 — 상담원 작성 필요"를 표시해야 한다(MUST)(근거: 명세서 FR-016 처리 5 "모든 후보가 기준 미만이면 근거 없음 … 초안은 만들지 않거나", FR-021 처리 2). 물은 것 가운데 일부에만 답하면 초안을 만들고 나머지는 팀이 확인한다고 써야 한다(MUST)(근거: 에이전트 설계서 v1.1 4-6 지시문 규칙 1). 언어 모델이 두 번 실패하면 초안 없이 "초안 생성 실패. 다시 시도"를 표시해야 한다(MUST)(근거: FR-021 예외 1행). 결과는 종류 FINAL_REPLY, 상태 DRAFT여야 한다(MUST)(근거: FR-021 처리 6).

#### Scenario: AC-021-1 견적 답변 초안
- **GIVEN** CSV1-000004
- **WHEN** 초안을 만든다
- **THEN** 프랑스어이고 "520.00 USD"(또는 같은 값의 표기), "4 semaines"(또는 동등 표현), 유효기간 30일이 있으며 숫자 출처가 product_master.csv이고, 끝에 영업 담당이 정확한 견적을 따로 안내한다는 문장이 있다

#### Scenario: AC-021-2 펌웨어 이미 최신
- **GIVEN** CSV1-000008 (아랍어, 접수 시점 최신 3.40)
- **WHEN** 초안을 만든다
- **THEN** "이미 최신" 취지의 아랍어 문장과 RN-ESS-BMS-V3 인용이 있고 3.50은 나오지 않는다

#### Scenario: AC-021-3 근거가 없으면 초안을 만들지 않는다
- **GIVEN** 근거 후보가 비어 있는 티켓
- **WHEN** 흐름이 돈다
- **THEN** 답변 초안이 없고 "근거 없음 — 상담원 작성 필요"가 표시된다

#### Scenario: 제안 AC-021-6 후보가 있어도 질문에 답하지 못하면 초안을 만들지 않는다
- **GIVEN** CSV1-000004와 같은 고객·제품(HMI-XGT-eXP60)이고 본문이 "패널 외함을 RAL 9005 색으로 칠해 줄 수 있나"인 기술 사양 문의(팀 정답지 GS-065와 같은 경우), 근거 후보는 DS-HMI-XGT-eXP60의 절들
- **WHEN** 흐름이 돌고 L4가 "근거가 물은 것에 답하지 못함"을 낸다
- **THEN** 답변 초안이 없고 "근거 없음 — 상담원 작성 필요"가 표시되며, 근거 후보 목록은 그대로 남는다

#### Scenario: 제안 AC-021-7 일부만 답하면 초안을 둔다
- **GIVEN** 질문 둘 중 하나만 근거 후보에 답이 있는 문의
- **WHEN** 흐름이 돌고 L4가 "일부만 답함"을 낸다
- **THEN** 답변 초안이 있고, 답이 없는 부분은 팀이 확인한다는 문장으로 쓰여 있다

#### Scenario: 제안 AC-021-8 복합 문의에서 한 문의만 답이 없음
- **GIVEN** 복합 문의에서 한 하위 문의의 L4가 "근거가 물은 것에 답하지 못함"을 낸다
- **WHEN** 다른 하위 문의의 답변 메일을 만든다
- **THEN** 그 하위 문의는 초안이 없고, 다른 문의 메일의 상태 목록에 "담당자 확인 중"으로 있다(AC-022-3과 같음)
