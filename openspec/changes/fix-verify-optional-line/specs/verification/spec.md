## MODIFIED Requirements

### Requirement: 초안마다 뜻의 문제 4가지를 찾는다 (FR-049)
검증 단계는 대역 뒤에 초안마다 언어 모델을 1회 불러 근거와 뜻이 다른 문장, 약속 표현, 질문과 다른 답, 한국어 대역 오역을 찾아야 한다(MUST)(근거: 명세서 FR-049 처리 1·2, 기술 명세서 v1.4 §2-1). 지적마다 항목, 해당 문장(quote), 이유를 남기고, quote가 초안이나 대역에 실제로 없으면 그 지적은 버려야 한다(MUST)(근거: FR-049 처리 3 "해당 문장", 기술 명세서 §3-2 L8 "quote가 초안 또는 대역에 실제로 있는지"). quote가 초안 본문의 문의 상태 목록(고정 문안) 안에만 있으면 그 지적도 버려야 한다(MUST)(근거: 명세서 FR-022 처리 3, 에이전트 설계서 v1.1 부록 A-2). 빠진 항목을 "가능하면 보내 주실 것"으로 청하는 끝의 한 줄은 정책으로 넣는 문장이므로 질문과 다른 답으로 지적하지 않아야 한다(MUST)(근거: 명세서 FR-021 처리 1, 에이전트 설계서 v1.1 12-1 가-5). 대역이 없으면 대역 오역만 빼고 검증하고 대역을 보지 못했다고 남겨야 한다(MUST)(근거: FR-049 예외 3행, 에이전트 설계서 v1.1 4-10절). 지적이 하나라도 있으면 "⑤ 걸림: {항목}", 없으면 "⑤ 통과"여야 한다(MUST)(근거: FR-049 처리 4). 검증은 초안을 고치거나 막지 않아야 한다(MUST)(근거: FR-049 처리 5, 기술 명세서 §3-3).

#### Scenario: AC-049-1 근거에 없는 할인은 약속 표현으로 걸린다
- **GIVEN** CSV1-000004 견적 초안에 근거에 없는 "30% 할인" 문장이 있고 코드 검사는 통과한 상태
- **WHEN** 검증한다
- **THEN** ⑤가 "걸림: 약속 표현"이고 그 문장이 강조할 문장(quote)으로 남는다

#### Scenario: AC-049-5 뜻이 다른 대역은 대역 오역으로 걸린다
- **GIVEN** 초안과 뜻이 다른 한국어 대역(시험용으로 만든 것)
- **WHEN** 검증한다
- **THEN** ⑤가 "걸림: 대역 오역"이다

#### Scenario: 제안 AC-049-7 문의 상태 목록은 질문과 다름으로 걸지 않는다
- **GIVEN** 복합 문의 CSV1-000008의 펌웨어 답변 메일(단락 + "Status of your requests:" 목록)이고, L8이 목록의 "2. Manual and document: …" 줄을 "질문과 다름"으로 지적한 상태
- **WHEN** 검증한다
- **THEN** 그 지적은 버려지고 ⑤가 "통과"다. 같은 메일의 단락 문장을 지적한 것은 그대로 남는다

#### Scenario: 제안 AC-049-8 "가능하면 보내 주실 것" 한 줄은 질문과 다름이 아니다
- **GIVEN** CSV1-000008과 같은 펌웨어 문의(고객 3.40, 접수 시점 최신 3.40)의 답변 초안이 "이미 최신"을 안내하고 끝에 "가능하면 제조번호를 보내 주십시오" 한 줄이 있으며, 고객 본문에는 제조번호가 없다
- **WHEN** 실제 언어 모델로 검증한다
- **THEN** 그 한 줄에 대한 OFF_TOPIC 지적이 없다
